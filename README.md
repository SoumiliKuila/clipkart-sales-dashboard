# clipkart-sales-dashboard | Power BI

📌 Project Overview

ClipKart Sales Dashboard is an interactive e-commerce sales analytics project developed using Microsoft Power BI and Excel.

The project focuses on analyzing sales performance, revenue trends, product categories, and city-wise sales to generate meaningful business insights and support data-driven decision-making.

🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Identify top-performing product categories.
- Understand city-wise sales performance.
- Track quantity sold and revenue trends.
- Identify business patterns through data visualization.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and visualization.
- Microsoft Excel – Data handling and preparation.
- CSV Dataset – Sales data source.

📂 Dataset Description

The dataset contains 1,000 sales records with the following columns:

Column| Description
OrderID| Unique order identification
Date| Order date
City| Customer city
Category| Product category
Product| Product name
Quantity| Number of items sold
Price| Product price
Revenue| Total revenue

Product Categories

- Electronics
- Clothing
- Groceries

Cities Covered

- Delhi
- Kolkata
- Mumbai
- Bangalore
- Chennai

📊 Key Performance Indicators (KPIs)

The project dataset can be used to analyze:

- Total Revenue
- Total Orders
- Total Quantity Sold
- Category-wise Revenue
- City-wise Revenue
- Product Performance

📈 Business Insights

The analysis helps understand:

- Which product categories contribute most to revenue.
- Which cities generate higher sales.
- How different products perform.
- Overall sales performance across the year.
